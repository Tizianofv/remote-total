Remote Total quedó instalado. Ábrelo desde Aplicaciones: aparece un icono en la barra de menú.

Configurar TotalMix FX (Global OSC), una sola vez:

  1. Options → Settings → OSC.
  2. En una ranura, marcar In Use y elegir Global OSC.
  3. Port incoming (entrada) = 7001; Port outgoing (salida) = 9001.
  4. Remote Controller Address / IP = 127.0.0.1.
  5. Desmarcar Peak Hold y desactivar Follow Submix.

Si macOS pregunta si Remote Total puede aceptar conexiones de red, permítelo: los celulares la necesitan.
